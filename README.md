# E-COMMERCER BACKEND powered by FastAPI
E-commerce is a type of retail that takes place online, meaning that instead of customers going to a physical store, they shop through the internet and the products are delivered to their homes. It's also called e-tail or online retail. Online shopping can be done 24/7 from the comfort of one's home, which makes it very convenient.

## create virtual environment
python3 -m venv venv

### activate virtual environment
source venv/Scripts/activate

### deactivate virtual environment
deactivate

### install dependencies
pip install fastapi uvicorn
